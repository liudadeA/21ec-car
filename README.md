# 2021 电子设计竞赛智能车资料

本仓库整理了 2021 年电赛智能车项目的单片机、树莓派视觉与模型训练代码。原来的训练资料压缩包已解压为可直接浏览的目录。

## 目录结构

- `firmware/stm32/`：STM32 下位机控制代码。
- `raspberry-pi/`：树莓派视觉、串口通信和相关测试脚本。
- `training/`：YOLO 训练与数据处理脚本。

## 说明

原仓库已有的 `.pt` 权重保留在 `raspberry-pi/`；压缩包中的训练输出、检测结果与其他可再生成产物未重复提交。部分 Python 脚本需要树莓派摄像头、串口设备或对应的 YOLO 运行环境。
